# Inventory Service

Este microservicio se encarga de gestionar el stock de los productos del catálogo. Permite consultar la disponibilidad, reservar stock temporalmente durante el proceso de checkout y descontar las unidades una vez confirmada la orden.

## Responsabilidades
- Mantener la consistencia del inventario.
- Validar disponibilidad de productos.
- Notificar faltantes o bajo stock.

## Configuración del Entorno
1. Clonar el repositorio.
2. Copiar el archivo `.env.example` a `.env` y configurar las variables.
3. Ejecutar el servicio (las instrucciones de ejecución se definirán según el stack final).
